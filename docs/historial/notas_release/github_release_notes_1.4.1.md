## English

Performance and polish: fixes against the 30 FPS lock on powerful PCs, the costume crash fixed, and a Kit with a **Diagnostics** page.

| Download | What it is |
|---|---|
| `DBZ-Budokai-3-HD-Collection-v1.4.1.zip` | **Game for Windows** (required). |
| `...-v1.4.1-linux-amd64.tar.gz` | Game for Linux (Vulkan). |
| [`DBZ3HD-1.4.0-Personajes.zip`](https://drive.google.com/file/d/1zpwuuU7ITKZlC43nsTbp6s2wceBcwO85/view?usp=sharing) | Optional: 7 new characters (**Google Drive**; the 1.4.0 pack works as-is). |
| `DBZ3HD-1.4.1-Kit-Modding.zip` | Optional: modding tools, now with Diagnostics. |

**Update:** extract over your install (**overwrite everything**) and press **PLAY**. Settings, mods and saves are kept.

**Changes**
- **30 FPS on powerful PCs (#8):**
  - precise Windows timing and no power-saving mode;
  - GPU crash diagnostics no longer cost performance.
- **Fixed** the select-screen crash when changing costume on a new character (Janemba).
- **Fixed** music going silent with the characters mod plus a music pack.
- **Fixed** the PLAY error when you have the character pack but not the Kit.
- The launcher warns that new characters only work with the USA game.
- **The log explains why a game is slow** (GPU, CPU or hitches), on Vulkan too.
- **Kit 1.1.0:** a Diagnostics page. Open a log and get a plain-language explanation of the problem.

**Known issues**
- **#8:** we could not reproduce it. If it still happens, attach your `dbz3.log` to the issue.
- **#14** (short freeze when transforming) and **#15** (fade to black on stage intros): still open.
