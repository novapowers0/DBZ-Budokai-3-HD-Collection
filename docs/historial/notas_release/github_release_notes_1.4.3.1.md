## English

**Performance and compatibility:** fixed 30 FPS and stutter on powerful PCs, and the game runs better on any GPU: integrated, laptops, AMD, Intel Arc and NVIDIA.

| Download | What it is |
|---|---|
| `DBZ-Budokai-3-HD-Collection-v1.4.3.1.zip` | **Windows game** (required). |
| `...-v1.4.3.1-linux-amd64.tar.gz` | Linux game (Vulkan). |
| [`DBZ3HD-1.4.3-Personajes.zip`](https://drive.google.com/file/d/1jDRwzd_idmeIxwAMN4q4bC89JKFiGXX7/view?usp=sharing) | Optional: 7 new characters (**Google Drive**, same as 1.4.3). |
| `DBZ3HD-1.4.3.1-Kit-Modding.zip` | Optional: modding tools, Python included. |

**Update:** extract over your install (**overwrite everything**) and press **PLAY**. Settings, mods and saves are kept.

**Performance**
- The FPS limiter no longer slows the game down (with the cap at 60 it could get stuck at 30).
- Steadier frames and a much lighter launcher.
- Stable even with heavy apps open (browser, recording, antivirus).
- The first fight no longer builds graphics effects on the fly, and loading with mods is snappier.
- **Tip:** don't cap FPS in the NVIDIA/AMD control panel or RivaTuner (it locks the game to 30); use the launcher's.

**Compatibility**
- Laptops with two GPUs: the dedicated one is always used.
- AMD RX 6000/7000/9000: fixed the "Graphics device lost" crash.
- Intel Arc: fast rendering path.
- If Direct3D 12 can't start on your PC, the game switches to Vulkan on its own.
- Smarter automatic preset for integrated and 4 GB GPUs.
- Graphics errors explained in Spanish and English. If the FSR 3 DLL is missing, the game still starts.

**Fixes**
- HD texture packs: no more wrong textures after changing characters.
- Linux: HD brightness works and Vulkan no longer drops to half speed.
- Capsule and UI text in French, German and Italian.
