## Español

**Modding sin complicaciones:** texturas en PNG desde el launcher, mods que se instalan arrastrándolos, aviso de mods rotos y un Kit que ya no pide instalar Python.

| Descarga | Qué es |
|---|---|
| `DBZ-Budokai-3-HD-Collection-v1.4.2.3.zip` | **Juego para Windows** (obligatorio). |
| `...-v1.4.2.3-linux-amd64.tar.gz` | Juego para Linux (Vulkan; sin DLSS ni FSR 3). |
| [`DBZ3HD-1.4.0-Personajes.zip`](https://drive.google.com/file/d/1zpwuuU7ITKZlC43nsTbp6s2wceBcwO85/view?usp=sharing) | Opcional: 7 personajes nuevos (**Google Drive**; el de la 1.4.0 sirve tal cual). |
| `DBZ3HD-1.4.2.3-Kit-Modding.zip` | Opcional: herramientas de modding, **con Python incluido**. |

**Actualizar:** descomprime encima de tu instalación (**sobrescribe todo**) y pulsa **JUGAR**. Se conservan ajustes, mods y partidas.

**Novedades (pestaña Mods del launcher)**
- **Texturas fáciles (PNG):**
  1. Activa *Capturar texturas mientras juego*.
  2. Pulsa *Preparar PNG*.
  3. Edita el que quieras sin cambiarle el nombre (hasta 4 veces más grande).
  4. Guárdalo en *Mi pack de texturas*.

  Se aplica solo al jugar.
- **Arrastrar y soltar:** suelta un mod `.zip` sobre la ventana del launcher y se instala. Si sueltas un PNG editado, va a *Mi pack de texturas*.
- **Aviso de mods rotos:** el launcher marca en amarillo, en lenguaje claro, y avisa junto a JUGAR:
  - los mods vacíos;
  - los mods metidos dentro de otra carpeta (con botón *Arreglar*);
  - los archivos que le faltan a un mod;
  - las texturas con un nombre o un tamaño que el juego no acepta.
- **Kit de modding con Python incluido** (carpeta `python`, con numpy, Pillow y scipy): ya no hay que instalar Python ni ejecutar `instalar_requisitos.bat`.

**Arreglos en los personajes de Shin Budokai** (importador del Kit)
- Los gritos nuevos se oían en silencio (Kamehameha y otros): ahora suenan.
- Técnicas de bola (Burning Attack): disparan, hacen daño, salen con su color y ya no hacen un salto raro hacia atrás.
- Mantener pulsada la ráfaga de ki cerraba el juego: ahora usan las ráfagas del personaje donante de Budokai 3.

**Problemas conocidos**
- El aura de ki no se ve en los personajes nuevos (se ven los efectos de carga).
- En Gohan del Futuro, Masenko y Z Sword aún no funcionan bien (vienen desactivadas).
- DLSS y FSR 3 siguen en beta.

## English

**Hassle-free modding:** PNG textures from the launcher, drag-and-drop mods, a broken-mod warning and a Kit that no longer asks you to install Python.

| Download | What it is |
|---|---|
| `DBZ-Budokai-3-HD-Collection-v1.4.2.3.zip` | **Game for Windows** (required). |
| `...-v1.4.2.3-linux-amd64.tar.gz` | Game for Linux (Vulkan; no DLSS or FSR 3). |
| [`DBZ3HD-1.4.0-Personajes.zip`](https://drive.google.com/file/d/1zpwuuU7ITKZlC43nsTbp6s2wceBcwO85/view?usp=sharing) | Optional: 7 new characters (**Google Drive**; the 1.4.0 pack works as-is). |
| `DBZ3HD-1.4.2.3-Kit-Modding.zip` | Optional: modding tools, **Python included**. |

**Update:** extract over your install (**overwrite everything**) and press **PLAY**. Settings, mods and saves are kept.

**New (launcher Mods tab)**
- **Easy textures (PNG):**
  1. Turn on *Capture textures while playing*.
  2. Press *Prepare PNGs*.
  3. Edit any of them without renaming it (up to 4× bigger).
  4. Save it in *My texture pack*.

  It applies automatically.
- **Drag and drop:** drop a mod `.zip` on the launcher window to install it. A dropped edited PNG goes to *My texture pack*.
- **Broken-mod warning:** the launcher flags these in yellow, in plain words, with a note next to PLAY:
  - empty mods;
  - mods inside an extra folder (with a *Fix* button);
  - files a mod is missing;
  - textures with a name or size the game won't accept.
- **Modding Kit with Python included** (`python` folder with numpy, Pillow and scipy): no Python install and no `instalar_requisitos.bat` anymore.

**Shin Budokai character fixes** (Kit importer)
- New yells were silent (Kamehameha and others): they play now.
- Ball techniques (Burning Attack) fire, deal damage, keep their color and no longer do an odd backward hop.
- Holding the ki-blast button crashed the game: ports now use the Budokai 3 donor's ki blasts.

**Known issues**
- The ki aura is not visible on new characters (charge effects are).
- On Future Gohan, Masenko and Z Sword still misbehave (disabled by default).
- DLSS and FSR 3 are still beta.
