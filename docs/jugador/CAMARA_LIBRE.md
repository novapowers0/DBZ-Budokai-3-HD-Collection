# Cámara libre

La cámara libre permite mover la vista durante una escena de combate. Es una función **BETA**, todavía en pruebas.

## Activarla

1. Entra en una escena de combate y abre el menú rápido con **F1**.
2. Entra en **MODOS** y activa **Cámara libre (BETA)**.
3. Para volver a la cámara normal, pulsa **R** en el teclado o **BACK** en el mando. También puedes apagar la opción desde F1.

Al activarla, los controles del mando dejan de manejar al luchador mientras mueves la cámara.

## Controles

| Control | Acción |
|---|---|
| **W / A / S / D** | Mover la cámara hacia delante, izquierda, atrás o derecha |
| **Q / E** | Bajar / subir |
| **Mantener el botón derecho del ratón y moverlo** | Mirar alrededor |
| **Mayús (Shift)** | Moverse más rápido |
| **Rueda del ratón** | Acercar o alejar la vista |
| **Palanca izquierda** | Mover la cámara |
| **Palanca derecha** | Mirar alrededor |
| **Cruceta arriba / abajo** | Subir / bajar |
| **LT o RT** | Moverse más rápido |
| **LB / RB** | Cambiar el zoom |
| **R / BACK** | Desactivar la cámara libre y volver a la cámara del juego |

## Pausa y HUD

Con la cámara libre activada, abre **F1 > MODOS** para mostrar estas opciones:

- **Pausar el juego**: pausa el juego mientras colocas la cámara; al quitar la pausa, la pelea continúa.
- **Ocultar HUD**: quita el marcador y otros elementos de la pantalla. Al desactivarlo, el HUD vuelve a su estado anterior.

## A tener en cuenta

- La cámara libre es **BETA** y puede no funcionar en todas las escenas o modos.
- Es una herramienta para explorar y encuadrar la escena; algunas pantallas y elementos propios de ciertos modos no siguen la cámara.
- **La opción no se guarda**: al iniciar el juego de nuevo estará apagada.
